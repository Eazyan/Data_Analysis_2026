# Датасет

Для отчета используется публичный CSV-датасет Titanic:

https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv

Файл содержит 891 строку и 15 столбцов с данными о пассажирах Титаника: класс билета, пол, возраст, тариф, порт посадки, факт выживания и другие признаки.

Локальная копия для воспроизводимости: `titanic.csv`.
