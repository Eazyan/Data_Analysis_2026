Репозиторий содержит три итоговых задания по дисциплине "Аналитик данных".

## Структура

- `Задание 1/` — отчет по промпт-инженерии для EDA.

Основной API-провайдер: OpenRouter. Текущая модель по умолчанию: `qwen/qwen3.6-plus`.
