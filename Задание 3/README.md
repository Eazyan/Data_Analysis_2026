## Идея

Веб-приложение на Streamlit принимает CSV/Excel-файл и текстовую инструкцию пользователя. После загрузки запускается LLM-агент, который анализирует данные через инструмент `run_python_code`: читает датасет, считает метрики, строит графики и формирует отчет на русском языке.

Основной провайдер: OpenRouter. Модель по умолчанию: `openai/gpt-4o`.

## Почему это агентное решение

LLM не получает заранее посчитанные характеристики датасета. Вместо этого модель сама вызывает tool `run_python_code`, получает результаты выполнения Python-кода и на их основе решает, какие проверки и расчеты сделать дальше.

## Защита от prompt-injection

- Системный промпт явно запрещает выполнять инструкции, найденные внутри данных.
- Датасет считается недоверенным источником, а не набором команд.
- Python tool блокирует опасные импорты и вызовы: `os`, `sys`, `subprocess`, `socket`, `requests`, `urllib`, `open`, `eval`, `exec` и другие.
- Код выполняется с таймаутом и сохраняет графики только в рабочую папку запуска.
- Приложение не раскрывает API-ключи и переменные окружения.

## Запуск локально

```bash
cd "Задание 3"
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

В `.env` нужно указать ключ:

```env
OPENROUTER_API_KEY=sk-or-v1-...
OPENROUTER_MODEL=openai/gpt-4o
```

Запуск:

```bash
streamlit run app/main.py
```

## Деплой на сервер

Минимальный вариант:

```bash
cd "Задание 3"
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
streamlit run app/main.py --server.address 0.0.0.0 --server.port 8501
```

После этого сайт будет доступен по адресу:

```text
http://SERVER_IP:8501
```

Для постоянной работы на сервере лучше завернуть запуск в `systemd` или Docker. Это можно сделать отдельным шагом перед публикацией.
